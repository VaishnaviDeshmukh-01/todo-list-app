# 📝 Todo List App

A simple and clean Todo List web app built using **HTML, CSS, and JavaScript**.
This app allows users to add, delete, and mark tasks as completed, with data saved in **localStorage**.

---

## 🚀 Features

* ➕ Add new tasks
* ❌ Delete tasks
* ✅ Mark tasks as completed
* 💾 Data persists using localStorage
* ⌨️ Press **Enter** to quickly add tasks
* 🎨 Clean and modern UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)

📁 Basic To-Do App
 ├── index.html

## ⚙️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Start adding your tasks 🚀
